PROYECTO DESTACADO · 2024

IACOW

Sistema de Gestión Ganadera

Sistema web desarrollado para la Asociación Ganadera Local de Macuspana para la gestión de socios y la comparación visual de diseños de fierros ganaderos.

Python Django PostgreSQL Procesamiento de imágenes

RESULTADOS

+2,000 diseños procesados
Etapa nacional INNOVATECNM 2024

DESCRIPCIÓN

Una solución para digitalizar la gestión y comparación de fierros ganaderos.

Desarrollé e implementé el sistema para centralizar la información de socios, automatizar tareas administrativas y facilitar la identificación de diseños mediante procesamiento y comparación visual de imágenes.

Organización Asociación Ganadera Local de Macuspana
Ubicación Macuspana, Tabasco
Periodo Enero – Noviembre 2024
Rol Desarrollador Full Stack

FUNCIONALIDADES

Componentes principales

01

Gestión de socios

Administración de información de socios y procesos asociados dentro del sistema.

02

Comparación visual

Procesamiento y comparación de diseños de fierros ganaderos para apoyar su identificación.

03

Credenciales

Generación automatizada de credenciales y soporte al flujo de impresión.

04

Automatización

Digitalización de tareas administrativas para reducir trabajo repetitivo.
